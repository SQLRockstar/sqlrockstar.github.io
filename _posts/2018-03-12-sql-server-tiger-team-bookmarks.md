Last week while I attended the <a href="https://mvp.microsoft.com/summit" target="_blank" rel="noopener">Microsoft MVP Summit</a>, I had the honor to attend sessions delivered by Pedro Lopes (<a href="https://blogs.msdn.microsoft.com/blogdoezequiel/" target="_blank" rel="noopener">blog</a> | <a href="https://twitter.com/SQLPedro" target="_blank" rel="noopener">@SQLPedro</a>) and his Tiger team. The SQL Server Tiger team are engineers that work with customers to solve their biggest issues and will help build and deploy patches as necessary. Together with the CAT team and Microsoft CSS, these three teams offer a level of customer support that is second to none in the industry.

During the Summit last week Pedro shared this slide that detailed a list of SQL Server Tiger team bookmarks:

<a href="https://thomaslarock.com/wp-content/uploads/2018/03/SQLTiger_Bookmarks.jpg"><img class="aligncenter size-large wp-image-18744" src="https://thomaslarock.com/wp-content/uploads/2018/03/SQLTiger_Bookmarks-600x303.jpg" alt="SQL Tiger Team Bookmarks" width="600" height="303" /></a>

(And yes, I was given permission to share this slide. Warrants mentioning before some jackhole tries to get me in trouble for violating my MVP NDA by sharing.)

The slide is great, and it's been shared by many. But it's not clickable, except on the Tiger team page <a href="https://blogs.msdn.microsoft.com/sql_server_team/" target="_blank" rel="noopener">here</a>. And even on that page, it is buried beneath the fold.

So, I thought it would be good to have more than one page on the internet with links because that's how the Google works (or so I've been told).

&nbsp;
<h2><a href="http://aka.ms/sqlserverteam" target="_blank" rel="noopener">SQL Server Tiger Team Blog</a></h2>
This is the official team blog for SQL Server Tiger team of engineers. If you aren't following this blog, you should. There is no better blog of in-depth technical details for SQL Server on the internet.

Located at: <a href="http://aka.ms/sqlserverteam" target="_blank" rel="noopener">http://aka.ms/sqlserverteam</a>

&nbsp;
<h2><a href="http://aka.ms/tigertoolbox" target="_blank" rel="noopener">SQL Server Tiger Team Toolbox</a></h2>
The GitHub repository for the SQL Server Tiger team, it contains "as-is" solutions and tools/scripts that published by team members. You won't find a better set of script for SQL Server. Many scripts floating around the internet all have their genesis from here.

Located at: <a href="http://aka.ms/tigertoolbox" target="_blank" rel="noopener">http://aka.ms/tigertoolbox</a>

&nbsp;
<h2 class="blog-title"><a href="http://aka.ms/sqlreleases" target="_blank" rel="noopener">SQL Server Release Services</a></h2>
The only blog you need to follow regarding SQL Server releases, including service packs, cumulative updates, and public previews.

Located at: <a href="http://aka.ms/sqlreleases" target="_blank" rel="noopener">http://aka.ms/sqlreleases</a>

&nbsp;
<h2><a href="http://aka.ms/bpcheck" target="_blank" rel="noopener">SQL Best Practices and Performance checks</a></h2>
One of the Toolbox items, you won't do better than this script for any server you need to manage. Written by SQL Server engineers, any similar script on the internet is second best.

Located at: <a href="http://aka.ms/bpcheck" target="_blank" rel="noopener">http://aka.ms/bpcheck</a>

&nbsp;
<h2 class="title"><a href="http://aka.ms/sqlstandards" target="_blank" rel="noopener">SQL Server Standards Support</a></h2>
This page contains detailed technical documents for the standards that are implemented in SQL Server. Stuff like ISO and ANSI and I've already fallen asleep. Seriously important, just not exciting, stuff.

Located at: <a href="http://aka.ms/sqlstandards" target="_blank" rel="noopener">http://aka.ms/sqlstandards</a>

&nbsp;
<h2 id="dbcc-traceon---trace-flags-transact-sql"><a href="http://aka.ms/traceflags" target="_blank" rel="noopener">DBCC TRACEON - Trace Flags</a></h2>
The BOL page that lists and describes the trace flags that are available (and supported) in SQL Server. Not every trace flag is listed. Trace flag behavior can vary between versions of SQL Server. Use with caution. Do not taunt trace flags.

Located at: <a href="http://aka.ms/traceflags" target="_blank" rel="noopener">http://aka.ms/traceflags</a>

&nbsp;
<h2><a href="http://aka.ms/sqllifecycle" target="_blank" rel="noopener">Microsoft Lifecycle policy</a></h2>
A comprehensive list of the support start and (most important) end dates for versions of SQL Server and related products.

Located at: <a href="http://aka.ms/sqllifecycle" target="_blank" rel="noopener">http://aka.ms/sqllifecycle</a>

&nbsp;
<h2 class="c-heading-3 article-heading ng-binding ng-scope"><a href="http://aka.ms/sqlupdates" target="_blank" rel="noopener">Where to find information about the latest SQL Server builds</a></h2>
A comprehensive list of all SQL Server builds going back to SQL 2005. It's a long list of links for downloading builds and service packs, but not for RTM downloads.

Located at: <a href="http://aka.ms/sqlupdates" target="_blank" rel="noopener">http://aka.ms/sqlupdates</a>

&nbsp;
<h2 id="sql-server-guides"><a href="http://aka.ms/sqlserverguides" target="_blank" rel="noopener">SQL Server Guides</a></h2>
A list of guides available that discuss general concepts. They apply to all versions of SQL Server unless stated otherwise. Topics include thread and task execution, query processing, and index design. There is so much information here it makes me wonder why anyone would ever bother writing blog posts ever again.

Located at: <a href="http://aka.ms/sqlserverguides" target="_blank" rel="noopener">http://aka.ms/sqlserverguides</a>

&nbsp;
<h2><a href="http://aka.ms/sqlfeedback" target="_blank" rel="noopener">SQL Server Feedback</a></h2>
This is where you go to provide feedback on SQL Server. It's the "<a href="https://thomaslarock.com/2017/12/microsoft-connect-resolved-wont-fix/" target="_blank" rel="noopener">new Connect</a>". If you have a comment or suggestion, this is the place.  It's the place where you upvote to fix the generic "binary or string data would be truncated" error message to provide meaningful information.

Located at: <a href="http://aka.ms/sqlfeedback" target="_blank" rel="noopener">http://aka.ms/sqlfeedback</a>

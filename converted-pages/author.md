My most recent book is [Pro SQL Server 2022 Wait Statistics: A Practical Guide to Analyzing Performance in SQL Server and Azure SQL Database](https://amzn.to/42TRJB4). This book is designed to help any data professional understand how the SQL Server engine processes a query request. If you know what your query is waiting for, you have the information necessary to help it run faster. 

A few years back I wrote a book called [ _DBA Survivor: Become a Rock Star DBA_](http://www.amazon.com/gp/offer-listing/1430227877?ie=UTF8&tag=sq0f-20&linkCode=am2&camp=1789&creative=9325&creativeASIN=1430227877). The book is designed to give a junior to mid-level DBA a better understanding of what skills are needed in order to survive (and thrive) in their career. In a nutshell, this book documents the mistakes and successes I had during my years as a production database administrator.

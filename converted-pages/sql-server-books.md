# SQL Server Books for Data Professionals

I remember what it was like when starting as a DBA. How do you know who you can trust to give you quality information? You don't, so you rely on your friends to recommend some good quality SQL Server books.

If you only had time to read one book before taking on a project, do you know which book to reach for, or order? It is my hope that the books I list here will be able to help you along.

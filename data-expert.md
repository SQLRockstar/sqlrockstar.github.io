I've spent much of my career working with data and performing database administration. My focus has always been to help clients and customers find ways to enjoy longer weekends.

With over 20 years experience in IT and as a database professional, I have worked with several database platforms including Informix, Oracle, Sybase, and Microsoft SQL Server as well as several development platforms (C++, PowerBuilder, Microsoft .NET).

I am a [Microsoft SQL Server MCM](http://www.microsoft.com/learning/en/us/certification/master.aspx#SQL), a [VMware vExpert](http://blogs.vmware.com/vmtn/2015/02/vexpert-2014-announcement-2.html), and also a [Microsoft SQL Server MVP](https://mvp.support.microsoft.com/default.aspx/profile/thomas.larock) having first received the MVP honor back in 2009 and every year since. I participate in the annual [Microsoft MVP Summit](http://mvp.microsoft.com/summit), providing valuable feedback on SQL Server products and tools to Microsoft.

I also served as President for the [Board of Directors](http://www.sqlpass.org/AboutPASS/BoardofDirectors.aspx) for the [Professional Association for SQL Server](http://www.sqlpass.org/AboutPASS.aspx), an independent, not-for-profit association, dedicated to supporting, educating, and promoting the Microsoft SQL Server community member.

My expertise in data and databases is only rivaled by my love of bacon, a love that borders on being an unnatural obsession and is certain to be my undoing. But before that happens feel free to [contact me](http://thomaslarock.com/contact-me/) if you are interested in working with me.
